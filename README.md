# RPG 2D

A Godot-based 2D RPG focused on spatial exploration, everyday student-life activities, supernatural mysteries and turn-based encounters.

The repository is at its foundation stage: project configuration, icon and the supplied Ninja Adventure asset pack exist; gameplay code and playable scenes do not yet exist.
